# My Fit Ideas

Personal Body Progress Tracker capstone project for MSIT 5910.

## Project Scope

This project is a minimum viable product focused on:

- User authentication
- Body measurement tracking
- Hydration tracking
- Dashboard summaries
- PostgreSQL data storage

## Technology Stack

- React frontend
- Node.js / Express REST API
- Prisma ORM
- PostgreSQL database
- GitHub version control

## Repository Structure

- docs/
- design/
- database/
- src/frontend/
- src/backend/

## Future Enhancements

Future versions may include nutrition tracking, wearable device integration, and AI-assisted recommendations.
