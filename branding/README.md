# My Fit Ideas Logo Asset Package

Phase 2.1 branding assets for the MyFitIdeas product.

## Contents

- `svg/`: editable vector masters and logo variants
- `png/primary/`: stacked and horizontal raster exports
- `png/icons/`: favicon, PWA, Android, and general icon sizes
- `png/social/`: square avatar exports
- `pdf/`: print-ready vector exports
- `docs/brand-tokens.css`: initial UI color and typography tokens

## Approved identity

- Primary green: `#0D8F43`
- Dark green: `#087237`
- Accent green: `#82D63A`
- Light accent: `#A6E85A`
- Text/navy: `#1F2937`
- Display typeface: Roboto Condensed Bold (Poppins Condensed can replace it if licensed/available)
- Body typeface: Inter
- Tagline: “Your Body. Your Journey. Your Best.”

The SVG files retain separate leaf, person, wordmark, and tagline elements for easy editing in CorelDRAW, Inkscape, Illustrator, or compatible tools.
