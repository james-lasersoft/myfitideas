# MyFitIdeas Brand v1.0

This directory is the approved production brand release derived from the canonical MyFitIdeas Master Symbol v1.0 and outlined Wordmark Master v1.0.

## Canonical decisions

- Product name: `MyFitIdeas`
- Wordmark: custom outlined vectors derived from Noto Sans Display SemiBold
- `MyFit`: Deep Stem Green `#1F8B43`
- `Ideas`: Charcoal `#263238`
- Top leaf: `#48BE30`
- Side leaves: `#5FCB3C`
- Head and body: `#A6E84A`

## Primary assets

- `svg/myfitideas-horizontal-color-v1.0.svg`
- `svg/myfitideas-stacked-color-v1.0.svg`
- Canonical symbol and wordmark remain in `branding/master/`

The complete raster, favicon, app-icon, social, UI, print, and design-token package is distributed as `MyFitIdeas_Production_Asset_Library_Brand_v1.0.zip`.
