# My Fit Ideas Brand Assets

This directory contains the official My Fit Ideas Brand Kit v1.0 for Android, web, social media, and print advertising.

## Package contents

- Editable SVG logo masters with separately named elements
- Android launcher, adaptive, notification, splash, and Play Store assets
- Web favicons, PWA manifest, Open Graph artwork, and design tokens
- Social media and print advertising templates
- Brand guideline PDF
- Complete downloadable ZIP archive

Use `MyFitIdeas_BrandKit_v1.0.zip` for the full production package. CorelDRAW can directly import the SVG master files included in the archive.
